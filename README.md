# Gerenciador de Notas — Frontend

Aplicação React que consome a API de Notas e permite criar, visualizar, editar e excluir notas em tempo real.

## Links

- **Frontend:** https://frontend-notas-mu.vercel.app
- **API:** https://api-notas-yd41.onrender.com

## Tecnologias

- React
- Vite
- CSS

## Funcionalidades

- Criar notas com título e conteúdo
- Listar todas as notas salvas
- Editar notas existentes
- Excluir notas

## Como rodar localmente

```bash
npm install
npm run dev
```

Acesse: http://localhost:5173

> Configure a variável de ambiente `VITE_API_URL` com a URL da API antes de rodar.
